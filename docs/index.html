Playground distritos electorales

Este es una demostración técnica de las bases de datos generadas con unRob/distritos-electorales-mx.

Cómo funciona

  1. Seleccionas tu ubicación geográfica en un mapa, o permites que tu navegador las obtenga usando el GeoLocation API.
  2. Tu navegador descarga una base de datos y realiza una consulta localmente.
  3. Los resultados aparecen en el mapa.

Variantes

  • SQLite - Descarga de 18Mb (sólo distritos federales y locales).
  • DuckDB - Descarga de 183Mb (sólo secciones federales).
